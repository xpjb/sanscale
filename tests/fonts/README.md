Roboto-variable-subset.ttf is a test-only subset of Google Fonts' Roboto variable
font, retrieved September 26, 2026 from google/fonts, ofl/roboto/Roboto[wdth,wght].ttf.
It retains the glyphs in “Bold” and the weight/width axes. FontTools subset produced
it with all name records retained. OFL-Roboto.txt contains the upstream license.
This fixture is not embedded in any application or library build.
